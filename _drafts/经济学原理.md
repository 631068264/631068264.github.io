# 经济学原理 微观+宏观

## 供给和需求

### 需求

**需求量**:买者愿意并且能够购买的一种物品的数量。

**需求定理**:认为在其他条件不变时，一种物品的价格上升，对该物品的需求量减少的观点。

**需求表**:表示一种物品的价格与需求量之间关系的表格。
**需求曲线**:表示一种物品的价格与需求量之间关系的图形。

![image-20231005124034976](https://cdn.jsdelivr.net/gh/631068264/img/202310051240018.png)

描绘了在其他条件不变的情况下，一种商品的价格与其需求量之间的关系。其倾斜的根本原因是**需求定律 (Law of Demand)**——**价格越低，消费者愿意且能够购买的数量就越多**。当价格变化时，我们是在**沿着**这条曲线移动。



![image-20231005125137091](https://cdn.jsdelivr.net/gh/631068264/img/202310051251145.png)

**需求的变化 (Shift in Demand):** 当价格以外的因素发生变化时，会导致整个需求曲线的移动。例如：

- **正常品 (Normal Good):** 指的是当您的收入增加时，您会购买更多的商品（如牛排、旅游度假）。
- **低档品 (Inferior Good):** 指的是当您的收入增加时，您反而会减少购买的商品，因为您会转向消费更高品质的替代品（如方便面，当收入增加后可能会更多地选择去餐馆）。
- **替代品 (Substitutes):** 指可以相互替代来满足同一种欲望的两种商品（如可口可乐与百事可乐）。当替代品价格上涨，消费者会转而购买我们正在分析的商品，使其需求增加。
- **互补品 (Complements):** 指需要共同使用才能满足同一种欲望的两种商品（如汽车与汽油）。当互补品价格上涨，其自身需求量会下降，连带导致我们正在分析的商品的需求也减少。

**均衡价格**，也常被称为**市场出清价格 (Market-Clearing Price)**，是指在市场上，一种商品的**需求量**恰好等于其**供给量**时的价格。

- 在这个价格水平上，所有愿意并且能够购买该商品的消费者都能买到。
- 同时，所有愿意并且能够出售该商品的生产者也都能卖掉。
- 市场上既没有卖不出去的积压货物（过剩），也没有排队都买不到的缺货现象（短缺）。

**均衡数量**是指在均衡价格下，消费者愿意购买并且生产者愿意出售的商品数量。这个数量是唯一的，因为在这一点上，买卖双方的意愿达成了完美的一致。

市场过剩，生产欲望降低，反之亦然

**需求曲线向右移动**，**人们更想要这个东西了！**。在任何价格下都想买得更多。这会打破原有的市场均衡，并最终推动**均衡价格和均衡数量双双上涨**。反之亦然

------

| 变量变化                     | 对需求曲线的影响                     | 对均衡价格的影响         | 对均衡数量的影响 |
| ---------------------------- | ------------------------------------ | ------------------------ | ---------------- |
| **价格**                     | 沿着曲线移动（价格升高，需求量减少） | 不适用（价格是内生变量） | 不适用           |
| **收入增加（正常品）**       | 曲线向右移动                         | 升高                     | 增加             |
| **收入增加（低档品）**       | 曲线向左移动                         | 降低                     | 减少             |
| **相关品价格上涨（替代品）** | 曲线向右移动                         | 升高                     | 增加             |
| **相关品价格上涨（互补品）** | 曲线向左移动                         | 降低                     | 减少             |
| **偏好增强**                 | 曲线向右移动                         | 升高                     | 增加             |
| **预期未来价格上涨**         | 曲线向右移动                         | 升高                     | 增加             |
| **买家数量增加**             | 曲线向右移动                         | 升高                     | 增加             |



### 供给

**供给量**:卖者愿意并且能够出售的一种物品的数量。
**供给定理**:认为在其他条件不变时，一种物品的价格上升，该物品的供给量增加的观点。
**供给表**:表示一种物品的价格与供给量之间关系的表格。

![image-20231005125805638](https://cdn.jsdelivr.net/gh/631068264/img/202310051258699.png)



**供给曲线 (Supply Curve):** 这是一条向右上方倾斜的曲线，它描绘了在其他条件不变的情况下，一种商品的价格与其供给量之间的关系。其背后的逻辑是**供给定律 (Law of Supply)**——**价格越高，生产者愿意且能够提供的数量就越多**，因为更高的价格意味着更高的潜在利润。





![image-20231005130702373](https://cdn.jsdelivr.net/gh/631068264/img/202310051307426.png)

**供给的变化 (Shift in Supply):** 当价格以外的因素影响了生产成本或生产意愿时，整个供给曲线就会移动。

- **投入品价格 (Input Prices):** 这是生产商品所需的原材料、劳动力等成本。当投入品价格上涨，生产成本增加，在任何给定的销售价格下，企业的利润都会减少，因此供给减少，曲线向左移动。
- **技术 (Technology):** 技术的进步意味着可以用更低的成本生产同样数量的商品。这会激励生产者增加供给，使供给曲线向右移动。



| 变量变化             | 对供给曲线的影响                                         | 对均衡价格的影响         | 对均衡数量的影响 |
| -------------------- | -------------------------------------------------------- | ------------------------ | ---------------- |
| **价格**             | 沿着曲线移动（价格升高，供给量增加）                     | 不适用（价格是内生变量） | 不适用           |
| **投入品价格上涨**   | 曲线向左移动 ( **供给曲线向左移动意味着“供给减少了”**。) | 升高                     | 减少             |
| **技术进步**         | 曲线向右移动                                             | 降低                     | 增加             |
| **预期未来价格上涨** | 曲线向左移动                                             | 升高                     | 减少             |
| **卖家数量增加**     | 曲线向右移动                                             | 降低                     | 增加             |



## 弹性 (Elasticity)

弹性是经济学中衡量“反应程度”的核心概念。它告诉我们，当一个变量变动1%时，另一个相关变量会变动百分之几。

- **弹性**衡量的是消费者对价格变化的敏感度。一个关键的应用在于它与**总收益 (Total Revenue)**（即价格 × 数量）的关系。对于企业经营者来说，这是至关重要的。
  - **富有弹性 (Elastic):** 需求量变化的百分比大于价格变化的百分比。这意味着**消费者对价格非常敏感**（如非必需品、有许多替代品的商品）。此时，如果企业提价，销售量的下降会非常剧烈，导致总收益反而减少。因此，对**富有弹性的商品应采取“薄利多销”的策略。**
  - **缺乏弹性 (Inelastic):** 需求量变化的百分比小于价格变化的百分比。这意味着消费者对价格不敏感（如必需品、成瘾性商品）。此时，**如果企业提价，销售量下降得不多，总收益会增加。**

| 特征              | 需求价格弹性                      | 价格上涨时总收益的变化 |
| ----------------- | --------------------------------- | ---------------------- |
| **富有弹性 (>1)** | 需求量变动百分比 > 价格变动百分比 | 减少                   |
| **缺乏弹性 (<1)** | 需求量变动百分比 < 价格变动百分比 | 增加                   |
| **单位弹性 (=1)** | 需求量变动百分比 = 价格变动百分比 | 不变                   |



| 弹性类型                         | 值的范围 | 变量关系                       | 示例               |
| -------------------------------- | -------- | ------------------------------ | ------------------ |
| **需求的收入弹性（正常品）**     | > 0      | 收入增加，需求量增加           | 汽车、旅游         |
| **需求的收入弹性（低档品）**     | < 0      | 收入增加，需求量减少           | 公共交通、方便面   |
| **需求的交叉价格弹性（替代品）** | > 0      | A商品价格上涨，B商品需求量增加 | 可口可乐与百事可乐 |
| **需求的交叉价格弹性（互补品）** | < 0      | A商品价格上涨，B商品需求量减少 | 汽车与汽油         |

## 政府政策 (Government Policies)

政府干预市场的初衷往往是为了增进公平或纠正市场失灵，但这些政策常常带来意想不到的后果。

 

- - **价格上限 (Price Ceiling):** 比如对房租的管制。如果设定的租金上限低于市场自发形成的均衡租金，房东的供给意愿会下降，而租客的需求会增加，最终导致严重的住房**短缺**。
  - **价格下限 (Price Floor):** 比如最低工资法。如果设定的最低工资高于市场均衡工资，企业愿意雇佣的劳动力数量会减少，而愿意工作的劳动者数量会增加，从而导致**过剩**——也就是失业。
  - **税收 (Taxation):** 税收的**归宿 (Tax Incidence)**，即税负的最终承担者，取决于供给和需求的相对弹性。**更缺乏弹性的一方将承担更多的税负**。例如，香烟的需求缺乏弹性，因此即使对烟草公司征税，它们也很容易通过提价将大部分税负转嫁给消费者。

| 政策                         | 对市场的影响                             |
| ---------------------------- | ---------------------------------------- |
| **价格上限（低于均衡价格）** | 导致短缺，可能产生黑市                   |
| **价格下限（高于均衡价格）** | 导致过剩，政府可能需要收购               |
| **对卖者征税**               | 供给曲线左移，买者支付更多，卖者得到更少 |
| **对买者征税**               | 需求曲线左移，买者支付更多，卖者得到更少 |
| **补贴**                     | 供给或需求曲线右移，价格下降，数量增加   |

## 企业行为与市场结构

### 生产成本 (Production Costs)

经济学家在做决策时，最关注的是**边际成本 (Marginal Cost)**——即多生产一个单位产品所带来的总成本的增加量。理性决策的原则是：当边际收益大于边际成本时，就应该继续生产；反之则应停止。

**短期 (Short Run)** 与 **长期 (Long Run)** 的区别在于是否存在**固定成本 (Fixed Costs)**。在短期，企业有厂房、设备等固定成本，即使停产也要承担。而在长期，所有成本都是可变的，企业可以自由进入或退出一个行业。

| 变量             | 短期内变化                                           | 长期内变化                           |
| ---------------- | ---------------------------------------------------- | ------------------------------------ |
| **产量增加**     | 总成本增加，边际成本通常先降后升，平均总成本先降后升 | 企业可以调整所有投入，进入或退出市场 |
| **固定成本增加** | 总成本和平均总成本增加，边际成本不变                 | 企业会重新评估是否留在市场           |
| **可变成本增加** | 总成本、平均总成本和边际成本都增加                   | 企业会调整产量                       |

### 市场结构 (Market Structure)

- **完全竞争 (Perfect Competition):** 是一种理想化的市场，企业是**价格接受者 (Price Taker)**，没有任何定价权。长期来看，由于自由进入，所有企业的经济利润都将为零。这是最具效率的市场结构。
- **垄断 (Monopoly):** 市场中只有一个卖家，存在很高的进入壁垒。垄断者有强大的定价能力，通过“产量少、价格高”的方式获取超额利润，但这会导致社会福利的损失。
- **垄断竞争 (Monopolistic Competition):** 介于前两者之间，市场中有许多企业，但它们销售的产品有差异（如品牌、包装）。企业有一定的定价权，但由于进入自由，长期利润也为零。
- **寡头 (Oligopoly):** 市场被少数几家大公司主导。这些公司的决策高度相互依存，常常会进行战略博弈（合作或竞争）。

| 市场类型     | 企业数量 | 产品差异 | 进入壁垒 | 企业定价能力       | 长期利润 |
| ------------ | -------- | -------- | -------- | ------------------ | -------- |
| **完全竞争** | 很多     | 无       | 无       | 无（价格接受者）   | 零       |
| **垄断竞争** | 许多     | 有       | 无       | 有一定程度         | 零       |
| **寡头**     | 少数     | 可能有   | 有       | 较强（相互依存）   | 可能为正 |
| **垄断**     | 一个     | 独一-    | 高       | 很强（价格制定者） | 可能为正 |

## 劳动市场 (Labor Market)

劳动市场与其他商品市场类似，工资就是劳动力的价格，由劳动力的供给（来自工人）和需求（来自企业）共同决定。

- 一个核心区别是，企业对劳动力的需求是一种**派生需求 (Derived Demand)**，它取决于企业所生产的最终产品的市场需求。例如，对程序员的需求之所以高，是因为市场对软件和互联网服务的需求旺盛。
- 劳动力的供给则涉及到工人在**工作（赚取收入）与闲暇**之间的权衡取舍。工资的变动会同时产生**替代效应**（工资更高，闲暇更“昂贵”，倾向于多工作）和**收入效应**（工资更高，收入增加，倾向于享受更多闲暇）。



| 变量变化                     | 对劳动力需求的影响   | 对劳动力供给的影响   | 对均衡工资的影响 | 对均衡就业量的影响     |
| ---------------------------- | -------------------- | -------------------- | ---------------- | ---------------------- |
| **产品价格上涨**             | 需求增加（曲线右移） | 不变                 | 增加             | 增加                   |
| **技术进步（互补性）**       | 需求增加（曲线右移） | 不变                 | 增加             | 增加                   |
| **技术进步（替代性）**       | 需求减少（曲线左移） | 不变                 | 减少             | 减少                   |
| **劳动者数量增加**           | 不变                 | 供给增加（曲线右移） | 减少             | 增加                   |
| **非劳动收入增加**           | 不变                 | 供给减少（曲线左移） | 增加             | 减少                   |
| **最低工资（高于均衡工资）** | 需求量减少           | 供给量增加           | 工资被人为提高   | 导致失业（就业量减少） |



## 衡量宏观经济表现 (GDP, CPI)

**国内生产总值 (GDP):** 在某一既定时期一个国家内生产的所有最终物品与劳务的市场价值

**消费者物价指数 (CPI):** 普通消费者所购买的物品与劳务的总费用的衡量标准。

**通货膨胀率:** 从一个时期到下一个时期物价指数变动的百分比。

| 变量变化 (其他变量不变) | 最终结果     | 经济学解释                                                   |
| ----------------------- | ------------ | ------------------------------------------------------------ |
| **消费 (C) 增加**       | **GDP 增加** | 消费是GDP的重要组成部分，消费增加直接拉动总需求和GDP增长。   |
| **投资 (I) 增加**       | **GDP 增加** | 投资，特别是企业投资，能够扩大生产能力，是经济增长的关键驱动力。 |
| **政府购买 (G) 增加**   | **GDP 增加** | 政府增加基础设施建设等公共支出，会直接增加总需求，从而刺激GDP增长。 |
| **净出口 (NX) 增加**    | **GDP 增加** | 出口大于进口，意味着国内商品和服务在国际市场上具有竞争力，能促进国内生产和GDP增长。 |
| **货币供给 增加**       | **CPI 上升** | 当货币供应量超过经济增长所需时，过多的货币追逐有限的商品，导致物价普遍上涨，CPI因此上升 |



### 经济增长与生产力

- **生产率:** 每单位劳动投入所生产的物品与劳务的数量。它是决定生活水平的关键因素。
- **物质资本:** 用于生产物品与劳务的设备和建筑物存量。
- **人力资本:** 工人通过教育、培训和经验而获得的知识与技能。
- **技术知识:** 社会对生产物品与劳务的最好方法的了解。

| 变量变化 (其他变量不变) | 最终结果                       | 经济学解释                                                   |
| ----------------------- | ------------------------------ | ------------------------------------------------------------ |
| **生产率 提高**         | **经济增长 加快**              | 生产率的提高意味着可以用同样的投入生产更多的产出，这是经济持续增长的根本动力。 |
| **储蓄率 提高**         | **长期经济增长 加快**          | 更多的储蓄可以转化为投资，增加资本存量，从而提高生产率和经济增长潜力。 |
| **教育水平 提高**       | **人力资本 增加, 生产率 提高** | 受过良好教育的劳动力拥有更高的技能和知识，能更有效地使用资本和技术，从而提升整体生产率。 |
| **技术进步**            | **生产率 提高, 经济增长 加快** | 新技术的发明和应用能够极大地提高生产效率，是推动经济长期增长的核心引擎。[[16](https://www.google.com/url?sa=E&q=https%3A%2F%2Fvertexaisearch.cloud.google.com%2Fgrounding-api-redirect%2FAUZIYQESaNGvEy_WtN4iwJIGrbR50pb4wRsTBS2g2a4v6XPzaowrAB1oiUwMU3NyYENPqFCj8m8-u3Z8hKa5hcIx9JPmJ_GsWY3pwBnuEH_2E-Ytm6l97xO-KQ4mghn2LKF4uLflrBRmA510qpgqkU7PaSsXyavokMYwocVCq54pB6FuLJ_ufBA%3D)] |

## 储蓄、投资与金融体系

金融体系由帮助将一个人的储蓄与另一个人的投资相匹配的机构组成，对促进经济增长至关重要。

- **金融市场:** 储蓄者可以借以直接向借款者提供资金的金融机构。
- **金融中介机构:** 储蓄者可以借以间接地向借款者提供资金的金融机构。
- **可贷资金市场:** 一个虚拟的市场，在这个市场上，储蓄者供给资金，而借款者需求资金。

| 变量变化 (其他变量不变)           | 最终结果                                    | 经济学解释                                                   |
| --------------------------------- | ------------------------------------------- | ------------------------------------------------------------ |
| **储蓄激励政策 (如税收减免)**     | **可贷资金供给 增加, 利率 下降, 投资 增加** | 鼓励储蓄的政策会增加金融市场上的资金供给，从而降低借贷成本（利率），刺激企业增加投资。 |
| **投资激励政策 (如投资税收抵免)** | **可贷资金需求 增加, 利率 上升, 储蓄 增加** | 鼓励投资的政策会增加企业对资金的需求，推高利率，进而激励更多人储蓄。 |
| **政府预算赤字 增加**             | **可贷资金供给 减少, 利率 上升, 投资 减少** | 政府为弥补赤字而借款，会减少可供私人部门投资的资金，导致利率上升和投资下降（挤出效应）。 |

## 失业

失业是指有劳动能力、正在寻找工作但没有找到工作的状况。失业率是衡量经济健康状况的重要指标。

- **劳动力:** 一个经济体中既包括就业者又包括失业者的总人数。
- **失业率:** 劳动力中失业者所占的百分比。
- **摩擦性失业:** 由于工人寻找最适合自己技能和偏好的工作需要时间而引起的失业。
- **结构性失业:** 由于某些劳动力市场上可提供的工作岗位数量不足以为每个想工作的人提供工作而引起的失业。
- **周期性失业:** 与经济周期的短期波动相关的失业。

| 变量变化 (其他变量不变)        | 最终结果            | 经济学解释                                                   |
| ------------------------------ | ------------------- | ------------------------------------------------------------ |
| **经济衰退**                   | **周期性失业 增加** | 经济衰退期间，总需求下降，企业减少生产和雇佣，导致失业率上升 |
| **最低工资 高于均衡水平**      | **结构性失业 增加** | 当最低工资标准被人为设定在高于劳动力市场供求均衡的水平时，会减少企业对劳动力的需求，从而导致失业。 |
| **工会力量 增强**              | **结构性失业 增加** | 强大的工会可能通过集体谈判将工资推高到均衡水平之上，导致与最低工资类似的失业效应。 |
| **信息技术 改善 (如在线招聘)** | **摩擦性失业 减少** | 信息的改善可以帮助工人和企业更快地匹配，缩短寻找工作的时间。 |

## 货币体系与通货膨胀

货币是人们用于相互购买物品和劳务的一组资产。货币供给的变动会影响物价水平

- **货币供给:** 经济中可得到的货币量。
- **货币中性:** 认为货币供给变动不影响真实变量的观点。
- **货币流通速度:** 货币易手的速度。
- **数量方程式:** M x V = P x Y，它把货币量、货币流通速度和经济中产出的美元价值联系在一起。
- **费雪效应:** 名义利率对通货膨胀率所进行的一对一的调整

| 变量变化 (其他变量不变)   | 最终结果                               | 经济学解释                                                   |
| ------------------------- | -------------------------------------- | ------------------------------------------------------------ |
| **中央银行 增加货币供给** | **长期物价水平 上升, 通货膨胀率 上升** | 根据货币数量论，当货币供给的增长速度超过经济产出的增长速度时，会导致通货膨胀。 |
| **通货膨胀率 上升**       | **名义利率 上升**                      | 费雪效应指出，为了保持实际利率不变，名义利率会随着通货膨胀率的上升而相应上升。 |

**名义利率**是我们在日常生活中最常接触到的利率。它是指**没有剔除通货膨胀因素**的利率。

- **定义：** 名义利率告诉你，你存入银行的钱，随着时间的推移，其**货币数额**会增长多快。 它是银行支付的利率，或者是你从债券上获得的回报率。
- **例子：**
  - 你在银行存了1000元，银行提供的年利率是3%。这里的3%就是名义利率。
  - 一年后，你的账户里会有 1000 * (1 + 3%) = 1030元。你的钱在**数量上**确实增加了30元。

**实际利率**则是**剔除了通货膨胀影响**的利率。它反映的是你的**购买力**的真实增长速度。

- **定义：** 实际利率衡量的是，你存入银行的钱，其**购买力**（能买到多少商品和服务）会增长多快。
- **例子：**
  - 我们继续上面的例子：你的名义利率是3%，年初有1000元。
  - 假设这一年的通货膨胀率是2%。这意味着，年初花1000元能买到的一篮子商品，到年末需要花费 1000 * (1 + 2%) = 1020元才能买到。
  - 年末你的账户里有1030元，而原来价值1000元的商品现在值1020元。所以，你的真实购买力实际上只增长了大约 (1030 - 1020) / 1020 ≈ 1%。
  - 所以，这个1%就是**实际利率**。

**费雪方程式** 名义利率、实际利率和通货膨胀率之间的关系可以用一个简单的公式来近似表示，这个公式被称为“费雪方程式”：

- **实际利率 ≈ 名义利率 - 通货膨胀率**
- 实际利率 ≈ 3% (名义利率) - 2% (通货膨胀率) = 1%



 

 



## 国际关系 (开放经济)

开放经济是指与世界上其他经济自由交易的经济。这包括商品、服务和金融资产的跨国流动。

- **净出口 (NX):** 一国的出口值减进口值，也称贸易余额。
- **资本净流出 (NCO):** 本国居民购买的外国资产减外国人购买的本国资产。
- **名义汇率:** 一个人可以用一国通货交换另一国通货的比率。
- **真实汇率:** 一个人可以用一国的物品与劳务交换另一国的物品与劳务的比率。
- **购买力平价:** 一种认为任何一单位通货应该能在所有国家买到等量物品的汇率理论。

| 变量变化 (其他变量不变)           | 最终结果                                                     | 经济学解释                                                   |
| --------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **国内利率 上升**                 | **资本净流出 减少, 真实汇率 升值, 净出口 减少**              | 较高的国内利率吸引外国投资，导致资本流入，推高本国货币的价值，使得出口商品更贵，进口商品更便宜，从而减少净出口。 |
| **政府预算赤字 增加**             | **真实利率 上升, 资本净流出 减少, 真实汇率 升值, 贸易赤字 增加** | 政府预算赤字导致利率上升，吸引外资，使本币升值，最终导致贸易赤字扩大。 |
| **贸易壁垒 (如关税) 实施**        | **真实汇率 升值, 净出口 不变 (长期)**                        | 关税会减少进口，但同时也会导致本币升值，从而抑制出口。长期来看，净出口不受影响，但贸易量会减少。 |
| **资本外逃 (资本净流出突然增加)** | **真实汇率 贬值, 净出口 增加**                               | 大规模的资本外流会导致本国货币在外汇市场上供给增加，从而导致其贬值。这使得出口商品更具竞争力，促进净出口增加。 |

## 总需求与总供给模型

总需求与总供给模型是宏观经济学家用来解释经济活动围绕其长期趋势的短期波动的基本模型

- **总需求曲线:** 表示在每一种物价水平时，家庭、企业、政府和外国客户想要购买的物品与劳务量的曲线。
- **总供给曲线:** 表示在每一种物价水平时，企业选择生产并销售的物品与劳务量的曲线。
- **滞胀:** 产量减少而物价上升的时期。

| 变量变化 (其他变量不变)       | 最终结果 (短期)                                  | 经济学解释                                                   |
| ----------------------------- | ------------------------------------------------ | ------------------------------------------------------------ |
| **消费者信心 增加**           | **总需求 增加, 产出 增加, 物价水平 上升**        | 消费者对未来感到乐观时，会增加消费支出，从而推动总需求曲线右移。 |
| **企业投资 增加**             | **总需求 增加, 产出 增加, 物价水平 上升**        | 企业对未来盈利预期乐观时，会增加对新设备和厂房的投资，从而推动总需求曲线右移。 |
| **政府增加支出**              | **总需求 增加, 产出 增加, 物价水平 上升**        | 政府增加购买商品和服务的支出，直接增加总需求。               |
| **石油等关键投入品价格 上涨** | **总供给 减少, 产出 减少, 物价水平 上升 (滞胀)** | 生产成本的突然增加会使企业在任何给定的价格水平下减少生产，从而导致短期总供给曲线左移。 |

## 财政政策与货币政策

政府和中央银行可以利用财政政策和货币政策来影响总需求，从而影响短期内的产出和就业

- **财政政策:** 政府决策者对政府支出和税收的安排。
- **货币政策:** 中央银行决策者对货币供给的安排。
- **乘数效应:** 当扩张性财政政策增加了收入，从而增加了消费支出时，引起的总需求的额外变动。
- **挤出效应:** 当扩张性财政政策引起利率上升，从而减少了投资支出时，所引起的总需求减少。

| 政策措施                             | 类型               | 最终结果 (短期)                           | 经济学解释                                                   |
| ------------------------------------ | ------------------ | ----------------------------------------- | ------------------------------------------------------------ |
| **政府增加支出 或 减税**             | **扩张性财政政策** | **总需求 增加, 产出 增加, 物价水平 上升** | 这类政策通过直接增加政府购买或增加家庭可支配收入来刺激总需求。 |
| **政府减少支出 或 增税**             | **紧缩性财政政策** | **总需求 减少, 产出 减少, 物价水平 下降** | 这类政策旨在通过减少政府购买或降低家庭可支配收入来抑制过热的经济和通货膨胀。 |
| **中央银行增加货币供给 或 降低利率** | **扩张性货币政策** | **总需求 增加, 产出 增加, 物价水平 上升** | 降低利率可以刺激投资和消费，从而增加总需求。                 |
| **中央银行减少货币供给 或 提高利率** | **紧缩性货币政策** | **总需求 减少, 产出 减少, 物价水平 下降** | 提高利率可以抑制投资和消费，从而降低总需求，以对抗通货膨胀。 |

## 货币

**充当一般等价物的特殊商品**核心功能

- **交易媒介：** 这是货币最基本的功能，它解决了物物交换中“需求的双重耦合”难题，极大地降低了交易成本，提高了经济效率。
- **价值尺度：** 货币为商品和服务提供了一个统一的计价单位，使得不同商品的价值可以进行比较。

- **支付手段：** 用于清偿债务、支付工资、税款等。

**债券与股票**

- **债券：** 是发行人（政府或企业）的**债务凭证**。购买者成为债权人，在未来获得固定的利息支付，并在到期时收回本金。其风险相对较低。
- **股票：** 是公司的**所有权凭证**。购买者成为股东，收益来源于股价上涨和公司分红，风险相对较高。在公司破产清算时，偿付顺序在债权人之后。

### 利率是借贷资金的价格

**名义利率**是我们在日常生活中最常接触到的利率。它是指**没有剔除通货膨胀因素**的利率。

- **定义：** 名义利率告诉你，你存入银行的钱，随着时间的推移，其**货币数额**会增长多快。 它是银行支付的利率，或者是你从债券上获得的回报率。
- **例子：**
  - 你在银行存了1000元，银行提供的年利率是3%。这里的3%就是名义利率。
  - 一年后，你的账户里会有 1000 * (1 + 3%) = 1030元。你的钱在**数量上**确实增加了30元。

**实际利率**则是**剔除了通货膨胀影响**的利率。它反映的是你的**购买力**的真实增长速度。

- **定义：** 实际利率衡量的是，你存入银行的钱，其**购买力**（能买到多少商品和服务）会增长多快。
- **例子：**
  - 我们继续上面的例子：你的名义利率是3%，年初有1000元。
  - 假设这一年的通货膨胀率是2%。这意味着，年初花1000元能买到的一篮子商品，到年末需要花费 1000 * (1 + 2%) = 1020元才能买到。
  - 年末你的账户里有1030元，而原来价值1000元的商品现在值1020元。所以，你的真实购买力实际上只增长了大约 (1030 - 1020) / 1020 ≈ 1%。
  - 所以，这个1%就是**实际利率**。

**费雪方程式** 名义利率、实际利率和通货膨胀率之间的关系可以用一个简单的公式来近似表示，这个公式被称为“费雪方程式”：

- **实际利率 ≈ 名义利率 - 通货膨胀率**
- 实际利率 ≈ 3% (名义利率) - 2% (通货膨胀率) = 1%

### 利率的决定因素

 利率水平由多种因素共同决定

- **可贷资金的供给与需求：** 这是最基本的决定框架。
- **通货膨胀预期：** 通胀预期上升，会导致利率上升。
- **经济周期：** 经济繁荣时，资金需求增加，利率趋于上升；经济衰退时则相反。
- **中央银行的货币政策：** 央行通过调控基准利率来影响整个市场的利率水平

**风险与期限结构：**

- **风险结构：** **解释了为何期限相同的不同债券**（如国债和公司债）利率不同，主要由**违约风险、流动性**和**税收因素**决定。

  **违约风险 (Default Risk)**

  - **定义**：指债券发行人无法按时支付利息或在到期日偿还本金的风险。
  - **无违约风险基准**：在美国，联邦政府发行的国债（U.S. Treasury bonds）被认为是无违约风险的，因为政府可以通过税收或印钞来确保偿还。因此，国债利率成为衡量其他债券风险的基准。
  - **风险溢价 (Risk Premium)**：任何存在违约风险的债券，其利率都必须高于同期限的国债利率。这个高出的部分，就是**风险溢价**，它是投资者因承担额外违约风险而要求获得的补偿。
    - 风险溢价 = 违约债券利率 - 无违约风险国债利率
  - **信用评级 (Credit Ratings)**：像穆迪（Moody's）、标准普尔（S&P）这样的信用评级机构，会对债券的违约风险进行评估并给出等级（如AAA, AA, A, BBB, BB...）。
    - **投资级债券 (Investment Grade)**：评级在BBB或Baa以上，违约风险较低。
    - **垃圾债券/高收益债 (Junk Bonds/High-Yield Bonds)**：评级在BB或Ba以下，违约风险较高，因此其风险溢价也远高于投资级债券。
  - **经济周期的影响**：在经济衰退期间，企业盈利能力下降，违约风险普遍上升，导致公司债与国债之间的利差（风险溢价）会**扩大**。

  **流动性 (Liquidity)**

  - **定义**：指一项资产能够以较低的成本快速转换为现金的能力。交易越活跃、买卖价差越小的市场，其流动性越好。
  - **影响**：美国国债市场是全球流动性最好的金融市场之一，其债券可以随时轻松卖出。而某些公司债券，特别是规模较小的公司发行的，可能交易量很小，流动性较差。
  - **流动性溢价**：资产的流动性越差，投资者越不愿意持有，因此会要求更高的利率作为补偿。因此，即使两张债券的违约风险和税收待遇完全相同，流动性较差的那一张利率会更高。国债与公司债的利差中，也包含了一部分对流动性差异的补偿。

  **税收因素 (Income Tax Considerations)**

  - **定义**：指债券利息收入的税收处理方式对利率的影响。
  - **典型例子**：在美国，市政债券（Municipal Bonds，由州和地方政府发行）的利息收入通常**免征联邦所得税**。
  - **对利率的影响**：由于存在税收优惠，投资者（特别是高税率人群）愿意接受市政债券提供的较低利率。
  - **定量分析**：假设你面临两个选择，一个是年利率为5%的应税国债，另一个是年利率为4%的免税市政债券，你的所得税率为30%。
    - 国债的**税后收益率** = 5% * (1 - 30%) = 3.5%
    - 市政债券的**税后收益率** = 4% （因为免税）
    - 在这种情况下，尽管市政债券的票面利率更低，但其税后回报对你更有吸引力。因此，在市场上，免税的市政债券利率会系统性地低于风险和流动性相似的应税债券（如国债或公司债）。
- **期限结构（收益率曲线）：** **解释了为何期限不同的同类债券利率不同**。书中介绍了三种理论：**预期理论、分割市场理论**和**流动性溢价理论**。

**利率现象**

- **共同变动 (Rates move together):** 不同期限的利率（如1年期、5年期、10年期国债利率）通常会同向变动。

- **普遍向上倾斜 (Upward slope is common):** 收益率曲线通常是向上倾斜的，即长期利率高于短期利率。

- **偶尔反转 (Inverted curve happens):** 偶尔，收益率曲线会向下倾斜（反转），即短期利率高于长期利率。这种情况通常被视为经济衰退的预警信号。



| 理论名                                    | 核心思想                                                     | 基本假设                                                     |
| ----------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 预期理论 (Expectations Theory)            | 长期利率是市场对未来短期利率的预期的**平均值**。             | 不同期限的债券是**完全可替代的 (Perfect Substitutes)**。<br />投资者对持有**1个10年期债券，还是连续持有10个1年期债券**，是完全无差异的，只要最终的预期回报率相同即可。他们唯一的决策依据就是预期回报率。<br />市场的套利行为会使得2年期利率最终稳定在3%左右。 |
| 分割市场理论 (Segmented Markets Theory)   | 不同期限的债券市场是**完全独立、互不相关**的。每个市场的利率都由其自身的供给和需求决定。 | 不同期限的债券是**完全不可替代的 (Not Substitutes at all)**。投资者有特定的期限偏好，并且不会轻易改变。<br />  **短期债券市场**（如3个月国库券）：主要参与者是商业银行和货币市场基金。他们追求**流动性**和**安全性**，需要随时变现，所以只对短期债券感兴趣。<br /> **长期债券市场**（如20年、30年国债）：主要参与者是养老基金和人寿保险公司。他们需要为其**长期负债**（如未来几十年的养老金支付）寻找匹配的长期资产，所以只对长期债券感兴趣。 |
| 流动性溢价理论 (Liquidity Premium Theory) | 这是**预期理论**和**分割市场理论**的结合与折中。它认为，长期利率等于**未来短期利率的预期平均值**，再加上一个**流动性溢价 (Liquidity Premium)**。 | 不同期限的债券是**可以相互替代的，但并非完全替代 (Imperfect Substitutes)**。投资者普遍偏好短期债券（因为流动性好，利率风险小），但如果长期债券能提供额外的补偿（即“溢价”），他们也愿意持有。这个溢价就是为了补偿持有长期债券所面临的更高风险。 |
|                                           |                                                              |                                                              |

总结

| 特征           | **预期理论 (Expectations Theory)**         | **分割市场理论 (Segmented Markets Theory)** | **流动性溢价理论 (Liquidity Premium Theory)** |
| -------------- | ------------------------------------------ | ------------------------------------------- | --------------------------------------------- |
| **核心观点**   | 长期利率是未来短期利率的**平均值**         | 各期限利率由**各自市场**的供需决定          | 长期利率 = **平均预期** + **流动性溢价**      |
| **债券替代性** | **完全替代**                               | **完全不可替代**                            | **不完全替代** (最佳折中)                     |
| **解释力**     | ✅ 共同变动<br>❌ **普遍上斜**<br>✅ 偶尔反转 | ❌ **共同变动**<br>✅ 普遍上斜<br>✅ 偶尔反转  | ✅ 共同变动<br>✅ **普遍上斜**<br>✅ 偶尔反转    |
| **现实接受度** | 理论基础，但不够完整                       | 过于极端，不符合现实                        | **最被广泛接受的理论**                        |





### 债券与股票

**金融市场**

金融市场的核心功能是在资金盈余方和资金短缺方之间进行有效的资源配置

- **分类：**
  - **按期限划分：** 货币市场（短期，一年以内）和资本市场（长期，一年以上）。
  - **按发行阶段划分：** 一级市场（发行市场）和二级市场（流通市场）。
- **主要构成：**
  - **债券市场：** 决定了利率的水平。
  - **股票市场：** 是企业融资的重要渠道，其价格波动对公众财富和企业投资决策有重要影响。



**债券：** 是发行人（政府或企业）的**债务凭证**。购买者成为债权人，在未来获得固定的利息支付，并在到期时收回本金。其风险相对较低。

**股票：** 是公司的**所有权凭证**。购买者成为股东，收益来源于股价上涨和公司分红，风险相对较高。在公司破产清算时，偿付顺序在债权人之后。



## 金融中介



金融中介（如银行、保险公司、基金公司）是金融体系的核心，它们通过降低交易成本和信息不对称（逆向选择和道德风险）来提高资金流转效率。

**功能：**

- **汇集储蓄并提供流动性**。
- **风险分担和分散**：通过资产组合多样化来降低风险。
- **专业化的信息生产**：进行信用评估，监督借款人。



### 解决的问题

 **交易成本 (Transaction Costs)**

- **搜寻成本：** 你去哪里找到那个需要资金、又信得过的公司？这需要花费大量时间和金钱。
- **法律成本：** 你们需要起草一份具有法律效力的合同，这需要专业的法律知识，成本高昂。
- **规模不匹配：** 你可能只有5万元，但公司需要5000万元。你的小额资金无法满足大额需求。

**信息不对称 (Asymmetric Information)**

这是金融中介存在的**最根本原因**。指交易的一方比另一方拥有更多、更关键的信息。这会引发两个严重问题：

- **逆向选择 (Adverse Selection) — 发生在交易之前**
  - **问题**：“我怎么知道谁是值得信赖的借款人？” 在贷款市场中，那些信用最差、风险最高的借款人，往往最积极地寻求贷款，因为他们最缺钱，也最可能不还钱。而优质的借款人可能因为觉得利率太高而不愿借款。如果你作为一个信息不足的普通放贷人，你很可能会吸引来一堆“坏苹果”（Lemons），导致血本无归。
  - **结果**：由于害怕选错人，放贷人可能干脆收紧贷款，甚至退出市场，导致整个金融市场萎缩。
- **道德风险 (Moral Hazard) — 发生在交易之后**
  - **问题**：“借款人拿到钱后会做什么？” 借款人可能会从事比承诺的风险更高的活动，因为一旦失败，损失主要由放贷人承担；而一旦成功，收益主要归自己。例如，公司用借来的钱去赌博，而不是去建厂。
  - **结果**：放贷人由于无法有效监督借款人的行为，可能会因为担心这种风险而拒绝放贷。

### 金融中介的核心运作功能

**降低交易成本**

- **实现规模经济 (Economies of Scale)**：银行可以将成千上万储户的小额存款汇集起来，形成一笔巨额资金，然后贷给需要大额资金的企业。通过标准化的流程和专业的法务团队，它们可以把为每笔贷款服务的平均成本降到极低。

**解决信息不对称问题**

这是金融中介最核心的价值所在。

- **解决逆向选择 → 筛选与信息生产 (Screening & Information Production)**
  - 金融中介（特别是银行）是**生产信用信息的专家**。它们会投入资源去**筛选**借款人，审查其财务报表、信用记录、商业计划和抵押品价值。通过这种专业化的筛选，它们能有效地将“好苹果”和“坏苹果”区分开来，从而敢于放贷。
- **解决道德风险 → 监督与执行 (Monitoring & Enforcement)**
  - 放贷后，金融中介会持续**监督**借款人的经营状况，确保资金被用于约定的用途。
  - 它们会在贷款合同中加入**限制性条款 (Restrictive Covenants)**，例如禁止借款人从事高风险投资、要求其维持一定的财务比率等，以此来约束其行为，降低道德风险。

**提供风险分担和资产转换服务**

这是前两项功能派生出的重要服务。

- **风险分担 (Risk Sharing) / 多元化 (Diversification)**：金融中介通过将资金分散投资到成千上万个不同的借款人或资产上（“不把所有鸡蛋放在一个篮子里”），极大地分散了风险。对于单个储户来说，即使银行的某个贷款违约了，他/她的存款也安然无恙。
- **资产转换 (Asset Transformation)**：这是金融中介神奇的“炼金术”。它们将储户的**短期、小额、低风险、高流动性**的存款，“转换”为给企业的**长期、大额、高风险、低流动性**的贷款。这种转换满足了经济中两类完全不同参与者的需求，极大地促进了投资和经济增长。

## 美联储的结构与目标

- **核心概念**：美联储（The Fed）是美国的中央银行，但其结构并非单一的中央集权机构，而是一个精心设计的、兼顾中央权力与地方利益的复合体系。
- **结构解析**：
  1. **联邦储备理事会 (Board of Governors)**：位于华盛顿特区，是核心决策机构，由7名理事组成，由总统提名、参议院确认。
  2. **12家联邦储备银行 (Regional Federal Reserve Banks)**：分布在全国12个主要城市（如纽约、旧金山、芝加哥），是系统的“操作臂膀”，负责执行政策、监管辖区银行，并反映地方经济状况。
  3. **联邦公开市场委员会 (FOMC)**：**这是决定货币政策的核心**，由7名理事和5名储备银行行长组成（纽约联储行长是常任理事，其余4名由其他11家行长轮流担任）。每年召开8次会议，决定联邦基金利率的目标范围。
- **政策目标**：美联储奉行国会赋予的**“双重使命” (Dual Mandate)**：
  1. **价格稳定 (Price Stability)**：控制通货膨胀，长期目标通常设定在2%左右。
  2. **最大化就业 (Maximum Employment)**：促进经济增长，使失业率保持在自然失业率水平。

**美联储在通胀和就业之间的权衡，是预测未来利率路径、进而判断债券、股票、房地产等大类资产走势的根本前提。**

## 货币供给过程 (The Money Supply Process)

- **核心概念**：货币供给并非由中央银行凭空创造和完全控制，而是由**中央银行、商业银行系统**和**公众（存款人）**三方共同决定的。
- **过程解析**：
  - **核心公式**：$$M = m × MB$$  ；$$m = (1 + c) / (r + e + c) $$
  - **基础货币 (Monetary Base, MB)**：也称高能货币，是央行的负债，包括流通中的现金和银行存放在央行的准备金。**这是央行唯一能直接控制的部分**。
  - **货币乘数 (Money Multiplier, m)**：描述了1单位基础货币能创造出多少广义货币（M1, M2）。它的大小取决于三个比率：
    - r (法定存款准备金率)：由央行设定。**商业银行必须将其吸收的存款的一部分以准备金的形式存放在中央银行账户中，而不能用于放贷的比例**  （例如 "降准" == **释放流动性**）
    - e (超额准备金率)：由**商业银行**决定。银行越愿意放贷，e越低，乘数越大。
    - c (现金漏损率)：由**公众**决定。公众越倾向于持有存款而非现金，c越低，乘数越大。

市场的流动性不仅取决于美联储的“水龙头”（MB），还取决于银行系统的“管道意愿”（e）和公众的“蓄水池偏好”（c）。在2008年金融危机后，尽管美联储通过量化宽松（QE）大幅增加了MB，但由于银行惜贷（e上升）、公众去杠杆，货币乘数m下降，导致货币供给的扩张效果打了折扣。**作为投资者，不仅要看央行在做什么，更要观察银行的信贷扩张意愿和市场的风险偏好，这共同决定了流向资产市场的真实资金量。**



**M0 (基础货币 / 流通中的现金)**

- **定义**：指**中央银行**发行的、在银行体系之外流通的现金，也就是公众和企业手中持有的纸币和硬币。
- **特点**：流动性最强，是即时的购买力。

**M1 (狭义货币)**

- **公式**：M1 = M0 + 活期存款 (Demand Deposits)
  - 在美国，M1 还包括其他支票存款。在中国，主要是指**企业活期存款**。
- **定义**：M1 是现实的、可以直接使用的购买力。活期存款可以通过支票、借记卡、转账等方式随时用于支付，其流动性几乎等同于现金。
- **经济意义**：M1 的增速通常被视为经济活动的**先行指标**。如果企业活期存款（M1的主要部分）快速增加，往往意味着企业经营活跃，交易频繁，对未来的经济前景看好。

**M2 (广义货币)**

- **公式**：M2 = M1 + 准货币 (Quasi-Money)
- **定义**：M2 不仅包括现实的购买力（M1），还包括**潜在的购买力**。
- **“准货币”主要包括**：
  1. **储蓄存款 (Savings Deposits)**：居民个人的储蓄账户。
  2. **定期存款 (Time Deposits)**：有固定期限的存款，提前支取会损失利息。
  3. **其他存款**：在中国还包括企业定期存款、财政存款等。在美国，还包括零售货币市场基金等。
- **特点**：准货币的流动性比活期存款稍差，需要一个简单的步骤（如去银行取款或转账）才能转换成直接的支付手段，但转换成本很低。
- **经济意义**：M2 是衡量社会总需求和未来通货膨胀压力的一个重要指标。它反映了包括潜在购买力在内的全社会总的流动性状况。中央银行的货币政策通常以 M2 的增长率为重要的中介目标之一。





## 货币政策理论与操作机制

- **核心概念**：中央银行通过一系列工具来影响货币供给和信用条件，进而实现其宏观经济目标。这个从政策工具到最终目标的过程，被称为**货币政策传导机制**。

- **操作机制**：

  1. **政策工具 (Policy Tools)**：
     - **公开市场操作 (Open Market Operations)**：**最主要、最常用的工具**。美联储在公开市场上买卖国债，买入则向银行系统注入基础货币（降息信号），卖出则抽离（加息信号）。
     - **法定存款准备金率 (Reserve Requirements)**：调整银行必须持有的准备金比例。效果过于猛烈，**增加银行经营的不确定性**， **可能导致信贷紧缩**，不常用。
     - **贴现率/再贷款利率 (Discount Rate)**：商业银行向央行紧急借款的利率。更多是作为一种信号和“最后贷款人”的工具。
  2. **操作目标 (Operating Target)**：美联储并不直接控制货币供给量，而是通过上述工具来钉住一个短期利率目标——**联邦基金利率 (Federal Funds Rate)**，即**银行间同业拆借市场的利率。**
     - 通过预期影响长期利率 ， 长期利率 = 未来一系列短期利率的预期平均值 + 期限溢价 (Term Premium)
     - **QE - 量化宽松** ，中央银行会亲自下场，**直接在市场上大量购买长期国债和抵押贷款支持证券(MBS)**。 （需求增加 → 债券价格上升 → **债券收益率**（即长期利率）下降。）
  3. **传导机制 (Transmission Mechanism)**：联邦基金利率的变化会通过多种渠道传导至整个经济：利率渠道、资产价格渠道（影响股价、房价）、信贷渠道（影响银行放贷意愿）、汇率渠道等。

  

  

  

  

  紧盯联邦基金利率期货，以判断市场对未来加息/降息路径的预期。当**美联储进入紧缩周期，短期利率上升**，会提高所有资产的贴现率，对成长股等长期资产的估值构成压力；同时，**借贷成本上升会抑制经济活动，影响企业盈利**。反之亦然。

## 汇率制度、外汇市场

- **核心概念**：汇率是一国货币相对于另一国货币的价格。外汇市场是进行货币交换的全球性市场。汇率制度决定了汇率的波动方式。
- **理论解析**：
  - **汇率制度**：主要分为**浮动汇率制**（由市场供需决定，如美元、欧元）和**固定汇率制**（与某种货币或一篮子货币挂钩，如过去的港币）。
  - **长期汇率决定**：**购买力平价理论 (PPP)** 认为，长期来看，汇率会趋向于使两国一篮子商品的价格相等。
  - **短期汇率决定**：**利率平价理论 (IRP)** 认为，短期内，两国利率之差会影响资本流动，进而影响汇率。**高利率国家的货币通常会吸引资本流入而升值。**

汇率是国际投资的“度量衡”。对于持有海外资产的投资者，**汇率波动是重要的回报来源或风险来源**。例如，一个美国投资者购买了日本股票，即使日经指数上涨了10%，但如果日元对美元贬值了10%，那么以美元计价的回报就是零。**一国的货币政策（特别是利率决策）是影响其短期汇率的最关键变量。** 

## IS-LM 与 AD-AS 模型在货币传导中的运用

**IS-LM 模型**（短期，价格不变）：

- **IS 曲线** (产品市场)：显示在不同利率水平下，使得产品市场达到均衡的总产出。利率下降 → 投资增加 → 总产出增加。
- **LM 曲线** (货币市场)：显示在不同总产出水平下，使得货币市场达到均衡的利率。总产出增加 → 货币需求增加 → 利率上升。
- **货币传导**：美联储实施**扩张性货币政策**（增加货币供给）→ **LM曲线右移** → 利率下降，总产出（收入）增加。
- r 利率， y GDP

![img](https://cdn.jsdelivr.net/gh/631068264/img/202510261146001.png)

**AD-AS 模型**（中长期，价格可变）：

- **总需求曲线 (AD)**：显示在不同价格水平下，社会总需求的大小。AD曲线的推导就源于IS-LM模型。
- **总供给曲线 (AS)**：分为短期（SRAS）和长期（LRAS）。
- **货币传导**：扩张性货币政策 → **AD曲线右移** → **短期内**，产出增加，物价上升；**长期来看**，产出回到潜在水平，但物价永久性地抬高了。

货币政策（移动LM和AD）和财政政策（移动IS和AD）如何相互作用，并影响经济增长（Y）和利率（i）。**当分析师说“货币宽松利好经济”时，他们脑海里浮现的就是LM曲线右移带来的产出扩张。当他们担心“过度刺激导致通胀”时，对应的就是AD曲线过度右移导致物价上涨。** 这是将政策语言转化为市场影响的理论桥梁。

## 通货膨胀、通胀预期与央行信誉

通货膨胀是物价总水平的持续上涨。而**通胀预期**——即公众对未来通胀的看法——在现代货币政策中扮演着比通胀本身更重要的角色。

- **通胀预期**：它会影响企业的定价、工会的薪资谈判以及投资者的决策。如果人们普遍预期高通胀，他们就会要求更高的工资和价格，从而导致通胀的“自我实现”。
- **央行信誉 (Credibility)**：一个有信誉的央行，能够有效地**“锚定” (Anchor)** 公众的通胀预期。如果公众相信央行会不惜一切代价将通胀控制在2%，那么即使出现暂时的价格冲击，他们也不会轻易调整自己的长期预期。
- **时间不一致性问题 (Time-Inconsistency Problem)**：这是央行面临的经典难题。央行有时有短期动机去制造“意外通胀”来刺激就业，但一旦这么做，就会丧失信誉，导致长期通胀预期失控。一个独立的、有信誉的央行正是为了克服这个问题而存在。

**通货膨胀是固定收益资产（债券）的头号天敌**，因为它会侵蚀未来的本金和利息的实际购买力。因此，债券市场的核心就是对未来通胀的定价。美国通胀保值债券（TIPS）与普通国债的利差，就直接反映了市场对未来通胀的预期。**一个央行的信誉是无价之宝。** 当市场开始怀疑央行控制通胀的决心时（即信誉受损），通胀预期就会“脱锚”，导致长期利率飙升，引发股债双杀。

## 金融危机 (Financial Crises)

金融危机并非简单的市场下跌，而是金融体系**信息处理和信用中介功能**的严重崩溃。

1. **资产价格泡沫与信贷繁荣**：危机的源头往往是宽松的信贷环境和非理性的资产价格上涨（如房地产泡沫）。
2. **信息不对称加剧**：随着金融创新的复杂化（如CDO, MBS），没人能真正搞清楚这些资产的真实风险（逆向选择问题加剧）。
3. **泡沫破裂与去杠杆**：一旦资产价格下跌，金融机构的资产负债表恶化，引发恐慌性抛售和“去杠杆”，导致信贷急剧收缩。
4. **银行恐慌与系统性风险**：对一家机构的担忧会迅速蔓延至整个系统（“雷曼时刻”），银行间市场冻结，信用完全枯竭。
5. **实体经济衰退**：信用的崩溃导致企业和个人无法获得融资，投资和消费急剧下滑，经济陷入深度衰退。

金融危机的核心特征是**流动性枯竭和“安全资产”的极端溢价**。在危机中，现金为王，而美国国债等高信用、高流动性的资产会受到疯狂追捧。理解危机的传导机制，有助于投资者在平时识别过度杠杆和资产泡沫的风险，并在危机发生时理解央行和政府采取“最后贷款人”和大规模救助措施的必要性。每一次危机，都是对旧有风险定价模型的一次颠覆，也是财富的巨大再分配过程。





# 公司理财

## 三大表

财务报表。这三大表从不同维度展示了公司的经营状况：

- **资产负债表（Balance Sheet）**：这是一个“静态”快照，展示了在特定时间点，公司的资产（公司拥有什么）、负债（公司欠谁的）以及股东权益（真正属于股东的部分）的状况。核心恒等式是：**资产 = 负债 + 股东权益**。理解这张表，重点在于区分**账面价值**（会计记录的历史成本）和**市场价值**（资产在当前市场的真实价值），后者对于评估公司真实价值更为重要。
- **利润表（Income Statement）**：这是一张“动态”报告，展示了公司在一段时间内的经营成果，即收入、成本、费用和最终的净利润。它告诉我们公司是否**盈利**。核心公式是：**净利润 = 收入 - 成本费用**
- **现金流量表（Cash Flow Statement）**：这张表是三大表的核心，因为它直接追踪“现金”这一公司命脉的来龙去脉。它将所有现金流分为三类：
  - **经营活动现金流**：公司主营业务产生的现金。这是判断公司核心业务是否健康的关键。
  - **投资活动现金流**：用于购买或出售长期资产（如土地、设备）的现金。
  - **融资活动现金流**：向股东（发股票）或债权人（借款）筹集资金，以及偿还债务、支付股利的现金。

## 资产和负债的计算与评估

**资产 (Assets) = 负债 (Liabilities) + 所有者权益 (Shareholders' Equity)**

一家公司所拥有的全部资源（资产），要么是借来的（负债），要么是股东投入及经营累积的（所有者权益）

**流动资产 (Current Assets)**:流动资产指预计在一年内或一个营业周期内可以变现或耗用的资产，它们反映了公司的短期偿债能力。

- **现金及现金等价物 (Cash and Cash Equivalents)**

- **应收账款 (Accounts Receivable)**
  - 公司因销售商品或提供服务而应向客户收取的款项。其初始记录金额是发票金额。

- **存货 (Inventory)**

**非流动资产 (Non-current Assets)**

- **固定资产 (Property, Plant, and Equipment - PP&E)** : 
  - 以其**历史成本**（购置或建造成本）入账。 之后，在使用寿命内，需要系统地计提**折旧 (Depreciation)**。
- **无形资产 (Intangible Assets)**
  - 外购(如专利权、商标权、特许经营权）和内部研发两种。

**流动负债 (Current Liabilities)**

- **应付账款 (Accounts Payable)**：公司因购买商品或接受服务而应支付给供应商的款项。其计算和评估较为直接，就是发票金额。
- **短期借款 (Short-term Debt)**：偿还期在一年以内的银行贷款或其他借款。其价值等于本金加上应计利息。
- **预收账款 (Unearned Revenue)**：公司已经收到客户的款项，但尚未提供相应的商品或服务。这也是一项负债，因为公司有义务在未来提供这些服务。

**非流动负债 (Non-current Liabilities)**

- **长期借款 (Long-term Loans)**：来自银行或其他金融机构的、偿还期超过一年的贷款。
- **应付债券 (Bonds Payable)**：公司向公众发行的长期债券。

**资产的评估核心在于“价值”**：无论是存货的“成本与可变现净值孰低”，还是固定资产和无形资产的“减值测试”，都是为了确保资产的账面价值不会被高估，反映其未来能带来的真实经济利益。

**负债的评估核心在于“义务”**：负债的计算相对更客观，关键在于准确反映公司未来需要偿还的义务金额和时间。对于长期负债，需要运用折现的原理来确定其现值。

## 股票估值

**绝对估值法（贴现法）**“货币的时间价值”，即未来的钱不如现在的钱值钱，需要将其折算成现值

- **股利贴现模型 (DDM)**：认为**股票的价值**等于其未来所有预期股利的现值总和，对于稳定派发股息的成熟公司，这是一个很实用的模型
- **自由现金流折现模型 (DCF)**：认为公司的价值等于其**未来所有自由现金流的现值总和**。这是最重要、最严谨的估值方法之一，因为它关注的是公司能自由支配的现金。

**相对估值法**: 这类方法通过比较目标公司与同行业其他公司的估值指标来判断其价值

- **市盈率 (P/E)**：即**股价除以每股收益** = price/ EPS，是最常用的相对估值指标之一。它可以理解为，在盈利不变的情况下，投资需要多少年才能收回成本
- **市净率 (P/B)**：即股价除以每股净资产，适用于资产密集型行业

## 资本预算

资本预算：决定公司的未来

**识别现金流：只看增量现金流（Incremental Cash Flows）**

- **忽略沉没成本 (Sunk Costs)** 
  - 为了评估项目，上个月花了50万请咨询公司做调研。这笔钱已经花了，不管你做不做项目都要不回来。所以在计算项目价值时，**不要**算进去
- **机会成本 (Opportunity Costs)**
  - 公司要把旧厂房改造成新生产线。虽然旧厂房不用花钱买，但如果你不改造成生产线，你可以把它租出去或者卖掉。这笔“放弃的租金”或“卖房款”就是成本。
- **副作用/侵蚀效应 (Erosion)** 
  - 苹果公司推出iPhone 15，可能会导致iPhone 14的销量下降。在计算iPhone 15项目的现金流时，必须扣除因它而损失的iPhone 14的现金流。
- **营运资本的变动 (Change in NWC)**
  - 项目开始时通常需要垫资买库存、留备用金，这叫“营运资本增加”（现金流出）。项目结束时，这些库存卖掉了，钱收回来了，记得要把它加回来（现金流入）。
- **税收与折旧 (Tax & Depreciation)**
  - 折旧不是现金流出（没给别人钱），但折旧可以抵税（少交税就是赚了钱）。
  - **核心公式：经营性现金流 (OCF) = 息税前利润(EBIT) + 折旧 - 税**



**机会成本**，也是**风险的定价**：准确**识别和计算现金流**，并确定一个合理的**折现率**，这个折现率通常是公司的**加权平均资本成本 (WACC)**

**加权平均资本成本 (WACC)**: 衡量公司综合资本成本的指标，它将不同融资方式的成本按其在资本结构中的权重进行加权平均。公司的目标是找到一个最优的资本结构，使得WACC最小化，从而实现公司价值最大化



现在我们有了现金流和折现率，该用什么工具来评价项目好坏？

- **净现值 (NPV)**：未来现金流的现值总和 - 初始投资。
  - 如果一个项目的NPV大于0，意味着这个项目能为公司创造价值，值得投资
  - 最科学的方法，因为它同时考虑了货币的时间价值、风险（通过折现率）和所有的现金流。
- **内部收益率 (IRR)**：项目自身的年化回报率。
  - **IRR > 折现率 (WACC)**
  - 老板们喜欢IRR，因为“回报率20%”比“净现值500万”更容易理解。
  - **缺点**：如果你遇到**非常规现金流**（比如项目中间又要追加一大笔投资，现金流符号变来变去），可能会算出两个IRR，这时候IRR失效。另外，在比较两个规模不同的项目时（投100赚50 vs 投1000赚200），IRR可能误导你选小的（50% vs 20%），但NPV会告诉你选大的。
- **回收期法 (Payback Period)**：计算收回初始投资所需的时间。
  - 如果回收期 < 公司设定的标准（比如3年），就投。
  - 缺点是忽略了回收期之后的现金流和货币的时间价值
  - 由于简单，常用于中小企业或风险极高、急需回笼资金的项目。它衡量的是**流动性**而非价值
- **获利指数 (PI)**：= 未来现金流的现值 / 初始投资， 每投资1块钱，能换回多少现值
  - **PI > 1**：投！（等同于 NPV > 0）
  - 当公司钱不够花（**资本配给 Capital Rationing**），只能在好几个好项目中选几个时，PI最好用。它帮你把钱花在“性价比”最高的地方。



> **NPV** 告诉你这笔投资能给公司**增加多少绝对价值**（做大蛋糕）。**IRR** 告诉你这笔投资的**效率/速度**有多快（蛋糕发酵的速度）。





## 资本结构

资本结构指的是公司如何组合使用债务（如银行贷款、发行债券）和股权（如发行股票）来进行融资

| 特征       | **债务融资 (Debt)** —— 如：发债、银行贷款            | **权益融资 (Equity)** —— 如：IPO、增发股票             |
| ---------- | ---------------------------------------------------- | ------------------------------------------------------ |
| **成本**   | **低**。债权人风险低（优先受偿），且利息可以抵税。   | **高**。股东风险高（最后拿钱），要求的预期回报率高。   |
| **风险**   | **高**（对公司而言）。必须按期还本付息，否则会破产。 | **低**（对公司而言）。股利不是必须发的，不会导致破产。 |
| **控制权** | 不稀释控制权（债权人不管你怎么经营）。               | 稀释控制权（引入了新股东）。                           |

**MM定理 (Modigliani-Miller Theorem)**：这是资本结构理论的基石

- **无税MM定理**：在一个完美的资本市场（无税、无交易成本等）中，**公司的价值与其资本结构无关**。

  - 通过借钱（增加杠杆）来提高每股收益（EPS），并不能增加股东财富。因为风险也随之增加了，通过借钱带来的收益会被风险抵消
  - $${\mathrm R}_{\mathrm E}\;\;\;={\mathrm R}_0\;\;\;+({\mathrm R}_0\;\;-\;{\mathrm R}_{\mathrm D}\;\;)\times(\mathrm D/\mathrm E)$$随着公司借的钱（D）越来越多，剩下的股东承担的风险急剧上升。虽然债务便宜，但为了补偿风险，股东要求的**权益回报率 (`RERE`)** 会直线飙升。
  - **一顿操作猛如虎，最后加权平均资本成本（WACC）保持不变。**

- **有税MM定理**：当考虑到公司所得税时，由于债务利息可以抵税（称为“**税盾效应**”），负债可以增加公司价值

  - 利息是在税前支付的，可以抵扣应纳税额。而股利是税后支付的。

  - > 在考虑税收的情况下，公司应该**100%负债**，因为这样公司价值最大。

MM有税定理是对的，为什么苹果、微软不全部借钱经营？因为现实中还有**破产成本**

**静态权衡理论 (Static Trade-off Theory)**，也是目前最主流的观点。它认为公司是在“税盾的好处”和“破产的坏处”之间做平衡。

1. **税盾收益 (Benefit)**：借钱越多，抵税越多，公司价值上升。
2. **财务困境成本 (Financial Distress Costs)**：
   - **直接成本**：请律师、会计师处理破产的费用。
   - **间接成本**：更可怕。因为你负债太高，客户不敢买你的长保修产品，供应商不敢给你赊账，优秀员工跳槽。这些在公司还没真破产时就已经造成了巨大损失。

**加权平均资本成本 (WACC)**
维持现有资产，必须支付给所有资金提供者（股东和债权人）的平均回报率。$$\mathrm{WACC}=(\mathrm E/\mathrm V)\times{\mathrm R}_{\mathrm E}\;\;+(\mathrm D/\mathrm V)\times{\mathrm R}_{\mathrm D}\;\;\;\times(1-{\mathrm T}_{\mathrm c}\;\;)$$

![image-20251122162139168](https://cdn.jsdelivr.net/gh/631068264/img/202511221621382.png)

- **对公司而言**：WACC是**最小化**的目标。当WACC最低时，公司价值最大（因为未来的现金流折现回来价值最高）。
- **对投资项目而言**：WACC是**及格线**（折现率）。前一个话题提到的NPV计算，通常就用WACC作为折现率。如果项目的回报率（IRR）低于WACC，那就是在毁灭价值。

## 股利政策

公司赚取利润后，可以选择将其留存用于再投资，也可以作为股利发放给股东。

 **为何支付股利**

- 股东更偏好确定的现金股利，而不是不确定的未来资本利得（股价上涨带来的收益）
- 稳定的股利支付向市场传递了公司经营状况良好、未来现金流稳定的积极信号，有助于提升投资者信心
- 支付现金股利可以减少管理层手中的自由现金流，从而降低他们将资金用于低效投资或个人挥霍的可能性，这有助于缓解股东与管理者之间的代理问题

**股票回购** :公司用现金在股市买回自己的股票并注销

- 减少流通在外的股票数量，从而提升每股收益（EPS）和股价，避开**现金股利**（股东拿到手马上要交“红利税”）的税
- 发股利一旦开始就很难停，回购是一次性的。今年钱多就买点，明年钱少就不买，市场不会像削减股利那样恐慌。

## 现金管理

当公司需要钱做新项目时，优先用谁的钱  **优序融资理论**

- **内部融资 (Internal Financing)** ：用**留存收益**（赚来的钱）
- **债务融资 (Debt)** ：内部资金不够，才去借钱。有利息压力，但比发股票便宜，且不稀释控制权。
- **权益融资 (Equity)** ：**成本最高**（投行承销费贵），一旦宣布增发新股，股价通常会跌。

长期决策决定公司飞多高，短期决策决定公司**会不会突然猝死**。现金越多越好（现金放在银行是贬值的），也不是越少越好（容易资金链断裂）。目标是**权衡流动性与收益性**。

- **现金持有量决策**：持有过多现金会损失投资机会，持有过少则可能面临无法支付账单的风险。
- **应收账款管理**：制定合理的信用政策，加快资金回笼。
- **存货管理**：在满足生产销售需求和维持较低库存成本之间取得平衡。
- **短期融资决策**：在需要时，通过短期贷款等方式来弥补现金缺口。

在分析财报时，盯着**经营性现金流**和**现金循环周期**。利润可以造假（通过应收账款），但现金流很难造假。如果利润很高但现金流一直为负，这家公司离暴雷不远了。

## 风险管理



**资产定价基础**：

- **风险与收益**：高风险通常伴随着高预期收益。风险分为
  - **系统性风险**（市场整体风险，无法通过分散投资消除，如经济衰退）
    - **无法**通过分散投资消除。无论你买多少只股票
    - **CAPM模型就是专门用来给这部分风险定价的。**
  - **非系统性风险**（个别公司或行业的风险，可以通过分散投资消除）。
    - 市场**不会**为这部分风险给你额外回报（因为它很容易消除）可以通过**分散投资**消除。
- **CAPM模型（资本资产定价模型）**：这是一个描述资产的**预期收益率与系统性风险**之间关系的模型。 其核心思想是，投资者承担的系统性风险越高，所要求的预期回报也应该越高。
- **β系数 (Beta)**：衡量一项资产相对于整个市场（系统性风险）的波动性。β=1表示资产与市场同步波动；β>1表示资产波动大于市场；β<1表示资产波动小于市场。



CAPM模型 ： 

![image-20251122172241446](https://cdn.jsdelivr.net/gh/631068264/img/202511221722539.png)

**直观理解**：你的预期回报率 = 躺赚的钱 + （辛苦费 × 辛苦程度）。



**价值 = 现金流 / 风险(WACC)**，那么价值最大化就有两条路：**增加分子（资本配置）** 或 **减小分母（风险管理）**。

**有效资本配置**：把钱挪到回报率最高的地方去

- **剥离不良资产**：如果一个部门的ROIC（投入资本回报率）长期低于WACC，它就是在毁灭价值。卖掉它！
- **并购与扩张**：寻找 NPV > 0 的机会。
- **回购股票**：如果实在找不到好项目，就把钱还给股东，提高每股价值。

**风险管理 (Risk Management)** —— 为什么要花钱买保险

- **降低财务困境成本**：如果油价大涨导致航空公司亏损违约，破产成本极高。通过对冲锁定油价，可以确保公司活下来。
- **增加举债能力**：现金流越稳定（风险越小），银行越敢借钱给你。借更多的钱意味着更多的“税盾”（利息抵税），从而降低WACC。
- **保证投资计划**：如果不管理风险，一旦汇率大跌导致现金流断裂，原本赚钱的好项目可能因为没钱投而被迫放弃。

## 并购、公司治理与国际化

**并购 (M&A)** 

并购（Mergers and Acquisitions）是企业扩张最快的方式，也是风险最高的方式，**并购本质上就是一个巨大的资本预算项目（NPV决策）**。

- **收入协同**：利用你的渠道卖我的产品（例如：腾讯收购游戏公司，导流）。
- **成本协同**：裁掉重复的HR和财务部门，合并工厂（例如：两大航运公司合并）

**并购的陷阱**

- A公司宣布收购B公司，通常**B的股价暴涨**（溢价收购），而**A的股价下跌**。

  - 为了买下B，A通常要支付比市价高出30%-50%的**溢价 (Premium)**。

  - 只要 **支付的溢价 > 协同效应**，这个并购案对A的股东来说就是 **NPV < 0** 的（亏本买卖）。

  - 管理层往往为了构建“商业帝国”或盲目自信而支付过高价格，这就是“赢家的诅咒”。

     

**公司治理与代理**

在现代公司中，所有权（股东）和经营权（管理层）是分离的。管理层作为股东的“代理人”，可能会为了自身利益（如高薪、奢侈消费）而损害股东利益，这就是**代理问题**。良好的公司治理机制，如设立独立的董事会、建立有效的激励与监督机制，是解决代理问题、保护股东利益的关键。

- **董事会 (Board of Directors)**：代表股东监督CEO，有权解雇CEO。
- **管理层薪酬 (Executive Compensation)**：这是最有效的工具。
  - **股票期权 (Stock Options)**：给CEO发股票，只有股价涨了，他才能赚大钱。这就把CEO的利益和股东**绑定**了。
- **公司控制权市场**：如果CEO经营得太烂，股价跌得太惨，公司就会被“野蛮人”（其他公司或激进投资者）低价收购，然后把管理层清洗掉。这种**被收购的威胁**，迫使管理层必须努力工作。

**国际公司理财**

当公司业务扩展到全球时，会面临更复杂的财务挑战，如**汇率风险**（不同货币间汇率波动带来的风险）和**政治风险**（东道国政治不稳定带来的风险）等。跨国公司需要运用各种金融工具和策略来管理这些额外的风险。

- **汇率风险 (Exchange Rate Risk)**

  - **交易风险**：你卖了一批货给美国，约定3个月后收100万美元。如果3个月后美元贬值了，你换回的人民币就少了，利润可能瞬间变成亏损。

  - **折算风险**：你在海外有分公司，年底合并报表时，由于汇率波动，导致账面资产缩水。

- **2. 怎么应对？**

  - **对冲 (Hedging)**：使用**远期合约 (Forwards)**、**期货**或**期权**锁住汇率。
    - 比如：现在的汇率是7.0，我担心未来美元贬值，我就签一个合约，约定3个月后不管市场价多少，我都按7.0卖出美元。

  - **不仅是金融手段**：也可以把工厂建在当地，收入是美元，成本也是美元，自然对冲。

- **3. 政治风险**
  - 比如你的矿山被当地政府没收，或者当地限制资金汇出。这需要在计算资本预算时，大幅提高**折现率 (WACC)** 来反映这种高风险。

**金融市场与机构**

- **一级市场 (Primary Market)**：**IPO、增发、发债**。这是公司真正拿到钱的地方。
- **二级市场 (Secondary Market)**：**股市交易**。这里是股东之间互换股票，钱并没有进公司。
  - **关键点**：二级市场的股价虽然不直接给公司钱，但它决定了公司在一级市场的**融资成本**。
  - 如果二级市场股价高，公司增发新股时就能以极少的股份换来巨额资金。

**有效市场假说 (EMH)**

- **弱式有效**：看图（技术分析）没用，历史价格由于包含了。
- **半强式有效**：看新闻、看财报（基本面分析）没用，公开信息都反映在股价里了。
- **强式有效**：这世界上没有秘密，内幕消息也没用。
- **现实意义**：大多数成熟市场介于“弱式”和“半强式”之间。这意味着作为公司理财专家，我们不要试图通过“预测股价走势”来做财务决策，而应该专注于**创造真实的价值（NPV > 0）**。

# 投资学

1. **实物资产 vs. 金融资产**
   - **实物资产 (Real Assets)**：创造财富的源头。比如土地、厂房、技术专利、大学教育。它们直接决定经济的生产能力。
   - **金融资产 (Financial Assets)**：**对实物资产所创造利润的索取权**。
     - *股票*：你拥有了该企业厂房、技术产生利润的剩余索取权。
     - *债券*：你拥有了该企业固定支付现金流的承诺。
   - **启示**：投资股票不是炒代码，而是买入背后的实物资产生产力。
2. **一级市场 vs. 二级市场**
   - **一级市场 (Primary Market)**：**“新股发行”**。公司发行股票/债券，投资者给钱给公司，资金流入实体经济。
   - **二级市场 (Secondary Market)**：**“二手交易”**（这是我们散户主要参与的地方）。你买股票的钱给了另一个投资者，而不是给了公司。
   - **启示**：二级市场的作用是提供**流动性**和**价格发现**。如果二级市场估值高，公司在一级市场融资就容易。

## 现代投资组合理论MPT

**均值-方差分析 (Mean-Variance Analysis)**

只要两个资产不是完全正相关，组合起来就能**降低风险（方差），而不降低预期收益**。

**有效前沿 (Efficient Frontier)**

资产组合画在一张图上（横轴风险，纵轴收益），最左上方的边界线就是有效前沿。

线上的组合，是性价比最高的。线以下的组合都是垃圾（承担了同样的风险，收益却更低）。

**最优风险组合与资本市场线 (CML)**

加入**无风险资产**（如短期国债、美元现金）后，我们从无风险利率点向有效前沿做一条切线。这条切线就是 **CML（资本市场线）**。



## CAPM与仓位管理实操

CAPM 告诉你：**只有系统性风险（市场风险）才配得到回报，非系统性风险（个股暴雷）是没用的风险，应该被分散掉。**

![image-20251123170014812](https://cdn.jsdelivr.net/gh/631068264/img/202511231700932.png)

你不想买基金，想自己买股，那么你的任务是**手动构建一个 Beta 符合你预期的组合**。

**步骤一：界定各资产的 Beta 属性**

- **美元现金 / 短期国债**：Beta = 0（绝对安全锚）。
- **消费股（如可口可乐、宝洁）**：Beta 通常在 0.5 ~ 0.8 之间（防御性，跌得少）。
- **科技股（如英伟达、特斯拉）**：Beta 通常在 1.5 ~ 2.0 甚至更高（进攻性，涨跌都加倍）。
- **债券（长债）**：Beta 通常很低甚至为负（对冲股票风险）。

**步骤二：确定你的目标 Beta（仓位管理的核心）**

- 如果你看好后市，想获得超越大盘的收益，你需要组合 Beta > 1。
- 如果你觉得市场有风险，想求稳，你需要组合 Beta < 1。
- 如果你极度恐慌，你需要组合 Beta 接近 0。

**步骤三：计算与配置（举例）**
假设你有 100 万美元。

- rfrf (现金) = 5%
- 预期大盘收益 = 10%
- 你想构建一个**进可攻退可守**的组合，目标总 Beta 控制在 **0.8**（比大盘稳一点，但也能吃到涨幅）。

**你的配置方案示例：**

1. **美元现金 (Beta=0)**: 预留 20% (20万)。 -> 贡献 Beta: 0.2×0=0
2. **债券 (假设 Beta=0.1)**: 配置 20% (20万)。 -> 贡献 Beta: 0.2×0.1=0.02
3. **剩下的 60% 资金（60万）怎么分？**
   - 设科技股 Beta = 1.6，消费股 Beta = 0.6。
   - 设科技股比例为 w，消费股比例(60%−w)
   - 我们需要：0+0.02+股票部分Beta=0.8
   - 即股票部分的加权Beta需要填补 0.78 的缺口。

![image-20251123172933208](https://cdn.jsdelivr.net/gh/631068264/img/202511231729360.png)

**专家的特别提醒（关于你自己买股）：**
CAPM 成立的前提是**非系统性风险被分散掉了**。如果你只买 **1只** 科技股和 **1只** 消费股，CAPM 对你**失效**。因为那只科技股可能因为财务造假暴雷（非系统性风险），而不仅是随大盘波动。
**结论：** 既然你不买基金，你至少需要持有 **15-20 只不同行业的股票** 才能让你的组合行为符合 CAPM 理论。

利息对个股和债券影响

- 美联储降息，你应该买入**长久期**债券（长债涨得比短债猛）；如果预测升息，缩短久期或持有现金
- 加息周期要减持科技股
- 满仓科技股不想卖，又怕财报暴雷，可以买入**看跌期权 (Put Option)** 作为一个保险。这在书中称为“保护性看跌期权策略”

# 证券分析



**投资操作是基于详尽的分析，在保证本金安全的前提下，追求满意的回报。**

- **详尽分析 (Thorough Analysis)**：不是看K线图，不是听小道消息，而是拆解财报、研究商业模式、计算内在价值。
- **本金安全 (Safety of Principal)**：这是底线。投资首先要考虑的是“我不亏钱”，而不是“我要翻倍”。
- **满意回报 (Satisfactory Return)**：注意，不是“超额暴利”，而是符合风险水平的合理利息或股息回报。

资产负债表 (Balance Sheet)、利润表 (Income Statement)、现金流量表 (Cash Flow Statement)

- 关注资产质量与负债结构，
- 看 EBIT（息税前利润  **在支付利息和所得税之前赚了多少钱**）是利息费用的几倍。这个指标不仅看债要用，看股也要用，因为它代表了公司的财务安全垫、看过去 7-10 年的平均 EPS
- **自由现金流 (FCF)**：经营活动现金流 - 资本开支（维护性）

**EBIT=净利润+利息费用（借了多少钱）+所得税（交的税）**

**利息保障倍数 (Interest Coverage Ratio)**：EBIT/利息费用  过去七年平均利润必须能覆盖利息的 3-4 倍以上
