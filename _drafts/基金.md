**趋势跟随**

1, 趋势跟随的假设基础是：一旦形成趋势，就会持续一定的时间

2, 难点：1, 快速，发现趋势**突破**后，立刻建仓；2，“假突破”

3, **大盘和板块的趋势跟随，个股大多数情况是服从大盘和板块， 选择最强势的板块或个股！！！**

5, 趋势是“基本面”决定的。我不太相信技术分析预测的“趋势”（特别是“艾略特波浪理论”）

**均值回归**

1, 均值回归的假设基础是：万物都具有周期 性，当一个方向走到极端，必然折返，趋于 向中线回归

2, 一定要寻找“**极值**”！！！举例：200日 均线的3个标准差！

3, 个股的“均值回归”不要“接飞刀”—— 等股价到达“**极值**”区域，盘整一段时间之 后再建仓

4, 严格止损！“硬止损”一定要遵守！

## 仓位管理

- 仓位管理, 一句话概括: 不对称性——建立你的仓位, 使它在 后市发展符合你的预期时, 你能赚得最多, 后市发展不符合你的预期 时, 你能亏得最少 (正面你赢, 反面你输)

- **试错**的角度建仓
- **集中持仓**! 散户同时持有2-5个方向, 5-10只股票足矣!
- 对冲持仓!
- “硬”止损。。。止损, 不只是减少一单的损失, 更是一种心态! 止损之后还可以重新建仓。
-  “软”止损, 我95%都提前“软”止损,“宁可错过, 也不硬扛”

当股价下跌在你的买入价1.5-3倍atr 的时候, 止损。

- 根据个股情况灵活选择, 一般建议选择1.5-2倍atr。
- 期权持仓根据正股的价格变化来止损; 此外持仓超过1个月, 虽然没到止损点, 一般也止损, 期权到期前1个月强制止损

# 期权

## 什么是期权

期权合约是买卖双方之间的标准化协议。与股票的直接买卖不同，期权交易的是"权利"而非资产本身。

**看涨期权（Call Option）**

看涨期权赋予买方在到期日之前以特定价格**买入**标的资产的权利。

**看跌期权（Put Option）**

看跌期权赋予买方在到期日之前以特定价格**卖出**标的资产的权利。



**期权定价基础**

$$C = S × N(d₁) - K × e^(-r × T) × N(d₂) 其中： d₁ = [ln(S/K) + (r + σ²/2) × T] / (σ × √T) d₂ = d₁ - σ × √T$$

| 变量     | 描述                     | 对价格的影响                                     |
| :------- | :----------------------- | :----------------------------------------------- |
| **C/P**  | 看涨/看跌期权价格        | 我们计算的输出结果                               |
| **S**    | 当前股票价格（现货价格） | S越高，看涨期权价值越高，看跌期权价值越低        |
| **K**    | 行权价格                 | K越低，看涨期权价值越高；K越高，看跌期权价值越高 |
| **T**    | 到期时间                 | 时间越长，看涨和看跌期权价值都会增加             |
| **r**    | 无风险利率               | 利率越高，看涨期权价值越高，看跌期权价值越低     |
| **σ**    | 波动率（Sigma）          | 波动率越高，看涨和看跌期权价值都会增加           |
| **N(x)** | 累积正态分布             | 公式中使用的概率函数                             |



**期权的本质是风险管理工具。买方支付权利金获得选择权，卖方收取权利金承担义务。**

买都是要掏钱的，卖赚期权费用（**权利金**），

- 买方不需要有和期权对等的股票现货数量，交易常用手段，可以选择是否行权。顶多亏买期权钱
- 卖方是承担某个时间买卖交易义务，强制性的，一旦是**实值期权**就会强制清算

|          | 买入期权（Long Options）                                     | 卖出期权（Short Options）                                    |      |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ---- |
| 优势     | 风险有限（最多损失权利金）<br>潜在收益可观 <br/>无需大量资金 <br/>杠杆效应明显 | 立即收取权利金 <br/>时间价值为友（Theta）<br/> 胜率相对较高 <br/>可以产生稳定收入 |      |
| 劣势     | 时间价值衰减（Theta）<br/> 需要准确的方向判断 <br/>到期可能归零 <br/>隐含波动率下降风险 | 潜在损失巨大（裸卖）<br/> 需要保证金 <br/>被行权的义务 <br/>收益有限但风险大 |      |
| 使用情况 | 预期大幅度价格变动<br/> 希望限制最大损失 <br/>账户资金有限 <br/>短期投机交易 | 预期价格区间震荡 <br/>寻求稳定收入<br/> 有充足的保证金 <br/>长期投资策略 |      |





| 交易类型 | 权利/义务 | 最大收益        | 最大损失        |
| -------- | --------- | --------------- | --------------- |
| 买入看涨 | 权利      | 无限            | 权利金          |
| 卖出看涨 | 义务      | 权利金          | 无限            |
| 买入看跌 | 权利      | 行权价 - 权利金 | 权利金          |
| 卖出看跌 | 义务      | 权利金          | 行权价 - 权利金 |

**期权到期了会怎样？**

- **实值期权：**通常会自动行权（美式期权），买方获得相应收益
- **虚值期权：**自动作废，买方损失全部权利金
- **提前平仓：**大多数交易者选择在到期前平仓，避免行权麻烦
- **现金结算：**指数期权通常现金结算，无需实物交割





## 期权价值

**期权价值的构成**

| 价值类型     | 定义                   | 计算方法                                | 影响因素         |
| :----------- | :--------------------- | :-------------------------------------- | :--------------- |
| **内在价值** | 期权立即行权的价值     | 看涨：现价 - 行权价 看跌：行权价 - 现价 | 标的价格变动     |
| **时间价值** | 期权未来可能增值的预期 | 权利金 - 内在价值                       | 剩余时间、波动率 |
| **总价值**   | 期权的市场价格         | 内在价值 + 时间价值                     | 所有因素综合     |







标的资产的**当前市场价格**直接影响**期权价值**，并决定期权的"**价值状态**"


| 价值状态       | PUT             | CALL  | 执行情况           | 内在价值          | 时间价值       | 随时间（正股S不变，随时间距离行权日越来越近） |
| -------------- | --------------- | ----- | ------------------ | ----------------- | -------------- | --------------------------------------------- |
| 实值期权 (ITM) | S > K  （价内） | S < K | 到期可行权         | MAX(\|S - K\|, 0) | 看涨 ：C+K - S | 走向非0值                                     |
| 平值期权 (ATM) | S ≈ K（持平）   |       |                    |                   |                |                                               |
| 虚值期权 (OTM) | S < K （价外）  | S > K | 到期不可行权，归零 | 0                 | 只有时间价值   | 归0                                           |

**假设正股S不变，随时间距离行权日越来越近，期权价格都会扣掉时间价值。**

## 波动率

波动率通常被认为是期权定价中最关键的因素，波动率代表市场对价格变动的预期。

- **历史波动率**：衡量标的资产过去的价格波动。使用特定期间内收益率的标准差计算。
- **隐含波动率 (IV)**：从当前期权价格推导出的市场对未来波动率的预期。通常被视为市场情绪的晴雨表。

**波动率对期权的影响  非线性影响** 

| 波动率水平          | 期权权利金     | 最适合的策略       |
| :------------------ | :------------- | :----------------- |
| **低IV (< 20%)**    | 较便宜的权利金 | 买入期权，借记价差 |
| **中等IV (20-40%)** | 适中的权利金   | 平衡策略           |
| **高IV (> 40%)**    | 昂贵的权利金   | 卖出期权，信用价差 |



## 希腊字母

### Delta

衡量期权价格相对于标的资产价格1美元变化的变化率

买方情况，卖方得加个负号

| 期权类型     | Delta范围 | 实值期权       | 平值期权 | 虚值期权   |
| :----------- | :-------- | :------------- | :------- | :--------- |
| **看涨期权** | 0 到 1    | 0.70 到 1.00   | ~0.50    | 0 到 0.30  |
| **看跌期权** | -1 到 0   | -0.70 到 -1.00 | ~-0.50   | 0 到 -0.30 |

![image-20251006170807723](https://cdn.jsdelivr.net/gh/631068264/img/202510061708095.png)

Delta为0.60的看涨期权意味着：

- 股价每上涨1美元，期权价值增加0.60美元
- 大约60%的概率到期时处于实值状态
- 需要60股来对冲1张期权合约（100股）

##### 交易应用：

- 基于方向性敞口的仓位调整
- 创建市场中性策略
- 估算盈亏情况
- 投资组合对冲计算

##### 要点：

- Delta随股价变动而变化（这就是Gamma）
- 深度实值期权的Delta接近±1
- 远虚值期权的Delta接近0
- Delta不是恒定的 - 它是动态的



### Gamma

**Delta 对标的资产价格变动的敏感度**  (Delta的变化率)

| **情况**     | **Gamma 的含义**                                             |
| ------------ | ------------------------------------------------------------ |
| **Gamma 大** | Delta 变化快。价格波动一点，期权的风险敞口（Delta）就会剧烈变化。通常出现在**平值期权**（ATM）附近。 |
| **Gamma 小** | Delta 比较稳定。价格波动不会显著改变期权的风险敞口。通常出现在**深度实值**或**深度虚值期权**。 |

**GEX = Gamma Exposure（Gamma 暴露值）**，**它衡量了整个市场（或某个标的）期权仓位对标的价格波动的总体“Gamma 敏感度”。**所有期权加权后的总体 Gamma 敏感度，代表市场的综合反应



**GEX > 0 （正 Gamma）**  买期权

- 市场（做市商）整体持有 **多头 Gamma**
- 他们在标的价格上涨时**卖出现货**、下跌时**买入现货** → **抑制波动**
- 市场处于 **稳定区间**，波动被“吸收”

**GEX < 0 （负 Gamma）**  卖期权

- 市场整体持有 **空头 Gamma**
- 做市商在上涨时**买入现货**、下跌时**卖出现货** → **放大波动**
- 市场处于 **不稳定状态**

### Vega

Vega衡量期权对隐含波动率变化的敏感性。它表示**隐含波动率每变化1%，期权价值将变化多少。** （Vega为0.10，隐含波动率每增加1%，期权价值增加$0.1）

对于看涨和看跌期权，

- 买方，**Vega始终为正** - 较高的波动率会增加所有期权的价值。
- 卖方，



**Vega特征**

| 平值期权                            | 到期时间                         | 波动率事件                                  |
| ----------------------------------- | -------------------------------- | ------------------------------------------- |
| 具有最高的Vega - 对波动率变化最敏感 | 长期期权比短期期权具有更高的Vega | 财报、FDA批准和经济数据会导致隐含波动率飙升 |
|                                     |                                  |                                             |
|                                     |                                  |                                             |

**理解Vega对于财报玩法和波动率交易策略至关重要。许多交易者在财报前买入期权，由于财报后的隐含波动率崩塌而亏损。**

| 市场条件 | 隐含波动率表现 | Vega影响     | 交易策略           |
| :------- | :------------- | :----------- | :----------------- |
| 财报前   | 隐含波动率扩张 | 对多头有利   | 买入期权，跨式组合 |
| 财报后   | 隐含波动率崩塌 | 对多头不利   |                    |
| 市场恐慌 | 隐含波动率飙升 | 多头大幅获利 | 持有保护性期权     |
| 平静市场 | 隐含波动率收缩 | 逐渐损失     | 卖出权利金         |

### Theta

距离到期日时间减少对期权价格产生的影响，期权每天不跌不涨，就会减去一个Theta值。

对于卖方友好，相对于买方赌得是一段时间出现单边行情。**对于多头期权（买方）Theta通常为负（随时间损失价值），对于空头期权（卖方）为正（从时间衰减中获益）。**

**Theta衰减特征**

| 非线性衰减                                   | 平值期权                                        | 周末效应                                    |
| -------------------------------------------- | ----------------------------------------------- | ------------------------------------------- |
| 时间衰减随着到期临近而加速，特别是在最后30天 | 具有最高的Theta，因为它们有最多的时间价值要损失 | 即使在市场关闭的周末和节假日，Theta也会继续 |
|                                              |                                                 |                                             |
|                                              |                                                 |                                             |

| 到期天数 | 每日衰减% | 衰减特征     |
| :------- | :-------- | :----------- |
| 90+天    | ~1%       | 缓慢稳定衰减 |
| 30-90天  | 1-2%      | 适度加速     |
| 7-30天   | 2-5%      | 快速加速     |
| 0-7天    | 5-20%+    | 指数级衰减   |

**Theta卖方（期权卖方）从时间衰减中获利，而Theta买方需要显著的价格变动来克服每日损失。**

### Rho

衡量期权对利率变化的敏感性，无风险利率每变化1%，期权价值将变化多少。

**对于短期期权，Rho通常是最不重要的希腊字母，但在LEAPS和重大利率变化期间变得重要。**

Rho何时重要

| 情况          | Rho影响 | 考虑因素               |
| :------------ | :------ | :--------------------- |
| LEAPS（>1年） | 高      | 利率变化显著影响定价   |
| 周期权        | 最小    | 基本可以忽略Rho        |
| 高利率环境    | 中等    | 影响更明显             |
| 深度实值期权  | 较高    | 更大的资本承诺受到影响 |

### **隐含波动率（IV）的暴击**   

**方向完全正确，但因为IV腰斩，最终亏损超过50%！**

| 事件     | IV变化    | 期权价值影响 | 典型场景             |
| :------- | :-------- | :----------- | :------------------- |
| 财报前   | 30% → 60% | +100%        | 期权被高估，新手接盘 |
| 财报后   | 60% → 25% | -58%         | IV崩塌，方向对也亏   |
| 重大新闻 | 25% → 45% | +80%         | 快进快出机会         |
| 平静期   | 35% → 20% | -43%         | 慢性死亡             |

**正确做法**

- 卖出高IV的期权（如Iron Condor）
- 买入期权价差（Bull Call Spread）
- 财报后等IV恢复正常再进场
- 使用更长期的期权减少IV影响
- 选择Delta 0.3-0.5的期权（轻度OTM到ATM）
- 至少留出2-3周时间，避免Theta加速
- 计算盈亏平衡点，确保合理
- 永远不要把期权当彩票
- **财报交易不是赌方向：**而是交易波动率的回归
- **高IV时应该卖出：**不是买入，让IV崩塌为你工作
- **使用价差降低成本：**单腿期权在高IV时太贵
- **概率思维：**75%概率赚1,600 好过 20%概率赚5,000

**根据市场预期选择最优策略**

### 末日期权

**⚠️ 0DTE交易的残酷真相：**

- **时间衰减极快：**每小时Theta可达20-30%
- **方向错误立即止损：**没有等待反转的时间
- **滑点严重：**买卖价差可能占期权价值的10-20%

4. **严格纪律：**达到止损/止盈立即执行，不犹豫

## 常用策略

### 在IV高位时卖出，IV回落时买回

- 财报前1-2天（IV达到顶峰）
- FDA审批前 （**美国食品药品监督管理局（FDA, Food and Drug Administration）** 对药品、医疗器械等相关产品的 **注册、审评和批准流程**。）
- 重大事件前（如产品发布）
- 市场恐慌时（VIX > 30）

### 动态Delta对冲

- **Delta 中性**

  - 卖出 Call（负 Delta）和 Put（正 Delta）相抵，组合整体方向风险接近为零。

  - 如果价格单边走强，Delta 会偏离 0，这时用 **买/卖标的股票** 动态对冲，把 Delta 调回中性。

- **赚 Theta**

  - 卖出期权的最大优势是 **时间价值衰减 (Theta decay)**。

  - 每过一天，期权价值减少，卖方就赚取这部分时间价值。

  - Delta 中性意味着你不靠方向赚钱，而是靠 **时间流逝** 赚钱。

- **暴露 Vega**

  - 因为卖出的是期权，组合对 **隐含波动率 (IV)** 敏感。

  - Vega < 0 ⇒ 如果市场波动下降，你的头寸会赚钱；如果波动突然上升（比如遇到财报、黑天鹅），你会亏钱。

**期权风险的希腊字母**

| 希腊字母      | 风险类型   | 定义                            | 管理方法       |
| :------------ | :--------- | :------------------------------ | :------------- |
| **Delta (Δ)** | 方向风险   | 标的价格变动1元时期权价格的变化 | Delta中性对冲  |
| **Gamma (Γ)** | 加速度风险 | Delta的变化率                   | 控制仓位规模   |
| **Theta (Θ)** | 时间风险   | 每天时间价值的损耗              | 选择合适到期日 |
| **Vega (ν)**  | 波动率风险 | 隐含波动率变动1%的影响          | 波动率择时     |
| **Rho (ρ)**   | 利率风险   | 利率变动1%的影响                | 通常影响较小   |





| 策略          | 希腊字母重点 | 市场观点   | 示例                    |
| :------------ | :----------- | :--------- | :---------------------- |
| **Delta中性** | Delta = 0    | 非方向性   | 多头跨式，铁鹰          |
| **Theta收获** | 正Theta      | 区间震荡   | 空头宽跨式，信用价差    |

**Charm** and **Vanna**

- **Charm (Delta Decay):** Charm 衡量的是 Delta 随时间衰减的速度。换句话-说，它告诉我们随着到期日的临近，期权的 Delta 会发生多大的变化。
  - **正 Charm:** 通常出现在价内看涨期权 (In-the-Money Calls) 和价外看跌期权 (Out-of-the-Money Puts) 中。随着时间流逝，它们的 Delta 会减小。对于一个持有多头的交易员来说，这意味着头寸的方向性风险会随着时间自然降低。
  - **负 Charm:** 通常出现在价外看涨期权 (Out-of-the-Money Calls) 和价内看跌期权 (In-the-Money Puts) 中。随着时间流逝，它们的 Delta 会增大。
- **Vanna (Volatility's Effect on Delta):** Vanna 衡量的是 Delta 对标的资产波动率 (Implied Volatility) 变化的敏感度。它揭示了波动率的变动会如何影响期权的 Delta。
  - **正 Vanna:** 意味着当波动率上升时，期权的 Delta 会增加。这通常与看涨期权相关。
  - **负 Vanna:** 意味着当波动率上升时，期权的 Delta 会减小。这通常与看跌期权相关。
- **Net Charm (按行权价):** Net_Charm_at_Strike = Call_Charm_at_Strike + Put_Charm_at_Strike
- **Net Vanna (按行权价):** Net_Vanna_at_Strike = Call_Vanna_at_Strike + Put_Vanna_at_Strike
- **高正 Charm (总体):** 预示着随着时间推移，市场可能会有向下的“漂移”压力
- **高正 Vanna (总体):** 预示着如果波动率上升，市场可能会有向上的动力。

why not 行业研报：

- 不是所有的行业都有行研报告（体量小，非商业）
